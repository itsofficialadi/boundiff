# Boundiff v0.1.0

Initial public release of Boundiff, a Codex-native engineering skill toolkit focused on bounded autonomy, narrow diffs, explicit verification, independent review, and careful release checkpoints.

## Included

- 16 reusable agent skills in `.agents/skills/`, plus root `AGENTS.md`.
- Documentation, templates, optional installer, packaging tests and GitHub Actions validation.
- Three disposable paired Codex evaluation fixtures with a standard-library-only runner.
- [Initial evaluation scorecard](../../evals/INITIAL_RESULTS.md) and [validated metadata audit](../../evals/METADATA_AUDIT.md).

## Initial pilot outcomes

Six sessions were completed using Codex CLI 0.163.0 and model `gpt-6.1-sol`, with a baseline and Boundiff variant for each case:

- **Pagination repair:** both produced the same two-line fix and passed the regression; Boundiff ran 7,651 additional enumerated cases, versus six named baseline cases.
- **Independent review:** both identified the seeded cross-tenant disclosure without modifying the reviewed repository. Baseline also reported an additional conditional missing-tenant-ID issue; Boundiff described integrity checks more explicitly.
- **Release checkpoint:** both stopped on an unexpected staged file and preserved Git state.

These are three *single* paired trials, not a statistically meaningful benchmark. The evaluation metadata and report excerpts have been inspected, but complete redacted machine-readable transcripts are not published. No token, cost, or latency comparison was performed; user-level Codex configuration was not isolated; the release fixture had no remote. **No claim is made that Boundiff generally outperforms baseline Codex, or that release/deployment safety has been proven.**
